# Prompt Import — Analyze / Preview / Merge / Replace

Status: implemented before V2.0 UX Final.

Prompt Import lets a user prepare MiniMax Music3 Caption/Lyrics in ChatGPT, LM Studio, another local LLM, or by hand, then convert that text back into the versioned Semantic Studio `project_json` without requiring an LLM at runtime.

## Entry point

`Music3 Semantic Studio` exposes an **Import Prompt** button on the normal ComfyUI node.

The importer is intentionally separate from Prompt Preview. Prompt Preview remains the read-only representation of what the V1 compiler will send to MiniMax Music3.

## Workflow

```text
External LLM / hand-written prompt
        |
        v
Import Prompt
        |
        +-- Caption / Structured Caption
        +-- tagged Lyrics
        |
        v
Analyze
        |
        v
Import Preview
  - detected Global fields
  - detected Vocal fields
  - section order/types
  - duration / energy
  - instruments / lyrics presence
  - warnings / approximations
        |
        +--> Merge detected fields
        |      or
        +--> Replace section structure
        |
        v
project_json
        |
        v
Open Semantic Studio for manual refinement
```

Nothing changes when text is pasted or analyzed. The node changes only after **Apply Import**.

## Supported Caption format

The highest-fidelity path is the same structured form generated by Semantic Studio:

```text
### Global Metadata
Genre: Lo-fi hip-hop with chillhop influences.
Tempo target: approximately 78 BPM in 4/4 meter.
Mood and emotional direction: dreamy late-night.
Production profile: warm tape and vinyl.

### Vocal Details
Lead vocal: androgynous; timbre soft and breathy; delivery half-spoken.
Harmony/backing vocals: sparse murmured doubles.
Vocal effects: tape delay.

### Arrangement
Intro (0:00–0:03 target, 18%): Use rain texture, vinyl crackle, Rhodes piano. Vocal treatment: hushed hums. Fade in gently.
Verse 1 (0:03–0:16 target, 38%): Use dusty drums, bass, Rhodes piano. Vocal treatment: soft. Keep space for the lead vocal.
Chorus 1 (0:16–0:23 target, 78%): Use full drums, bass, guitar. Vocal treatment: power. Open the stereo image.
```

Exact percentage energy values are preferred. If only Semantic Studio's descriptive energy phrase is available, Prompt Import estimates an energy value and displays an approximation warning.

Section time ranges are converted back into per-section durations.

## Tagged Lyrics

```text
[Intro]
Mmm...

[Verse]
Midnight and the canvas glows

[Chorus]
Let it render on

[Verse]
Queue another frame
```

Repeated tags are assigned in occurrence order (`Verse 1`, `Verse 2`, etc.). Caption Arrangement sections and Lyrics blocks are paired by section type occurrence.

Supported tags map to the V1 section set: Intro, Verse, Pre-Chorus, Chorus, Post-Chorus, Bridge, Instrumental, Solo, Outro. `Hook` and `Refrain` are accepted as Chorus aliases; common instrumental/solo aliases are also normalized.

If Lyrics contain a section that is absent from the Caption, the importer creates that section with conservative default duration/energy and surfaces a warning.

A combined response may include `### Lyrics` after the Caption. When the separate Lyrics field is empty, the importer splits that combined response automatically.

## Merge vs Replace

### Merge detected fields

- update only Global/Vocal fields that were actually detected
- match sections by section type occurrence (`Verse 1` -> first existing Verse, `Verse 2` -> second existing Verse)
- update detected section properties
- append missing imported sections
- do not reorder unrelated existing sections

### Replace section structure

- Global/Vocal fields that were detected still update the existing project
- if imported sections were detected, rebuild `timeline.sections` in imported order
- if no sections were detected, the existing structure is left intact

Both modes preserve:

- `project_id`
- unknown future top-level fields
- `audio_edits`
- `takes`
- `conditioning_tracks`

## Free-form prompts

Prompt Import is deterministic and does not ask an LLM to reinterpret ambiguous prose. It can recover recognizable labeled fields from partially structured text, but it does not guess arbitrary song structure from free-form paragraphs.

For reliable one-paste import, a later step will define a reusable **LLM System Prompt / Music3 Studio template** for ChatGPT, LM Studio, and other LLMs. That template is intentionally separate from the importer implementation.

## Tests

Parser/merge tests use Node's built-in test runner and add no runtime dependency:

```bash
npm run test:import
```

The suite covers structured Caption + tagged Lyrics, Merge preservation, Replace section order, and repeated Lyrics section numbering.
